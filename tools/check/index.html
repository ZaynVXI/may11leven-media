Check · free M-Pesa message checker

Got money "by mistake"? Check before you send it back.

Paste the message and who sent it. Check looks for the warning signs Safaricom and fraud reporters describe. Nothing you paste leaves this page.

Example loaded: a typical fake

Whatever the result, do this

  1. Check your real balance. Dial *334# or open the M-PESA app. If the money isn't there, it was never sent.
  2. Don't send money back, reverse it or call the number back. If someone says they sent money by mistake, ask them to forward their message to 456 so Safaricom can reverse it.
  3. Report the fake. Forward the message to 333 so the number can be blocked.

Check looks for common warning signs. It can't see your M-Pesa account, so it can never prove a message is real. Your balance is the only proof. Check is an independent tool and isn't connected to Safaricom.
