# Branding and identity: what's current
- Unfixed identities: marks that flex across motion, screens and physical space, not one static logo (creativebloq)
- Responsive logo systems: a family of marks (full, compact, icon) tuned per size and context (creativebloq)
- Tactile 3D marks: clean depth, soft shadow, gentle bevel; premium, not 2010s skeuomorphism (creativebloq)
- Organic "earthmarks": soft curves and earthy palettes in food, wellness, home (creativebloq)
- Playful over safe: personality beats bland geometric sans sameness (creativebloq)
- Subtle iteration: refreshes of type and layout instead of full rebrands; a selling point for existing businesses (creativebloq)
- Belief and belonging: identity built on cultural meaning and community; strong for African and Gulf brands rooted in place (creativebloq)
- Obrazur (100K-630K views per reel): one brand per 6-8 s beat-cut reel - symbol on a backlit silhouette, construction grid, named swatches with HEX/RGB/CMYK/Pantone, type specimen, then the brand on its industry's own objects (truck, strap, flag, cap, billboard); one saturated colour per brand; collections of marks/app icons get saved (instagram.com/obrazur)
- Graphic trends now (Winterton series): mixed type (several typefaces and styles in one composition), rebus (symbols/images replacing letters, e.g. I-heart-NY, Rand's IBM), ASCII art (images built from characters, retro-tech), micrographics (dense spec labels: asset IDs, barcodes, certification marks, coordinates - from industrial labels; Virgil Abloh, 3.11LABS) (zacharywinterton.com reels)
- Holographik systems: palette = greyscale ramp (A01-A05) + white + warm off-white + ONE accent with tints, used for 'memorable moments'; one neutral grotesk with a 4-step type scale; wordmark spacing set by the golden ratio; graphic language of dot, line, dashed line; product naming family (ANI Lyzer, Sense, Biome, Qlinic) (behance.net/Holographik)
- Holographik decks (Colonize Mars, DeepBook): off-white pages, black label bars (Brand / Mission / Vision) over tiny text, giant two-letter monogram (CM) bottom-left, thin perspective line drawings, one accent colour (Mars orange, DeepBook blue), stat pages with huge numerals (2k, 30.8), roadmap as stacked tinted pages; DeepBook motion: isometric blocks (Lego-like) assembling, price ticker wheel with one highlighted value, candlestick chart on dotted grid, code scrolling behind the mark (behance.net/Holographik)
## How we use it
- Daily style study: pick 2 Holographik boards/reels and one other ref; copy the principle (palette ratio, type scale, one motif) into one of our concepts that week.
- Make our own demos of each trend for concept brands; add a micrographics label set to our kit for packaging, merch and UI.
- New format: 'identity in 8 seconds' reels for concept brands in our markets, plus a 'concept marks collection'.
- Always deliver a responsive mark set plus one motion behaviour; show it in a reel.
- Offer "refresh, not rebrand" to businesses that already have recognition.

## Holographik CoMinVi lessons (identity)
- Borrow a symbol system the industry already owns (periodic table symbols) and put the real material inside the letters.
- One industrial accent (safety orange) used only for frames, map dots, wireframes.
- Icon set in one thin stroke; type specimen + numerals shown as part of the case study.
