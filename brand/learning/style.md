# The house taste: minimal, simple, useful (Holographik first)
## Colour
- Greyscale ramp (black, 4-5 greys) + white + one warm off-white + ONE accent with 3-4 tints; accent only for one action or one moment per frame (ANI.AI orange button/28%, DeepBook blue Buy block, Mars orange roadmap)
- Event/culture work can go two-colour only (Bottone: red + black)
- Never shouty, never more than one saturated hue
## Typography
- One neutral grotesk for everything (ANI.AI: ABC Normal); hierarchy from a 4-step size scale (~130/75/33/18), not from extra faces
- Big numerals for the key number (28%, 8/30, 398, 2k, 30.8); tiny calm body text
- Black label bars (Brand / Mission / Vision) over small text; giant two-letter monogram bottom-left (CM)
- Wordmarks spaced by a ratio (golden ratio), construction lines shown
## Motifs and ideas
- Dot, line, dashed line as the whole graphic language; data as art (point constellations with 0.00x numerals, radar rings with a trajectory, timelines with one accent dot)
- Isometric blocks assembling (DeepBook), price wheel with one highlighted value, candlesticks on a dotted grid, code scrolling behind the mark
- Thin perspective line drawings on off-white decks
- Product names as a family rolling past (ANI Lyzer / Sense / Biome / Qlinic)
## How they present it
- Brand-book pages on mid-grey as a grid; floating UI collage on black; phone held by a silhouette hand; laptop on a concrete ledge; monitors in a dark room; white product on white; dieline line-art
- Motion: slow reveals, dots connecting, letters fading in with their grid, calm scrolls; event = posters in real streets + flash photos of the night

## Holographik colour + type, measured (CoMinVi)
### Palette (sampled from the screenshots and reels)
- Page grey #E0E0E0 (the IG/presentation backdrop) · White #FFFFFF cards · Sage-white #EBF0EC / #DDE2E1 (cool greenish off-white panels, never pure grey) · Near-black #151515 (dark cards, pills, text) · Mid grey ~#9B9795 (warm stone grey for faded list items)
- Night blue #344968 lives only in the 3D hero photo, not in the UI
- ONE accent: safety orange ~#E3782D–#F07018 (industry colour: hard hats, machines). Used for poster frames, one map region, the wireframe machine, a single services tile. Never on body text.
- Colour comes from the material: green copper ore, red earth, crystal blue, the rocks carry the colour so the UI can stay grey.
- Ratio: ~45% sage/grey, ~40% white, ~10% black, ≤5% orange.
### Typography
- One tight neo-grotesk (Neue Haas / Helvetica Now feel) for everything; our free match is Inter Tight Medium with -3% tracking.
- Weights: Medium for headlines, Regular for body; no bold, no italic, no serif.
- Scale: hero ~5% of width, statement paragraphs as headlines (3–4 lines, full sentences, tight 1.0 leading), stats large, body tiny (~1% of width) set in short justified/left blocks bottom-right.
- Mono (Plex Mono-like) UPPERCASE tiny for data labels only: "OVER TIME +837.650 LINEAR METERS", "MINERALS WE EXTRACT", "PB [#82]".
- Hierarchy by opacity, not size: active item black, the rest the same size at ~20% grey (mineral list, client wheel, values list Honesty/Respect/Integrity).
- Statement headline starts after an inline label (S.04 box + black pill) so the label sits in the first line's indent.
- Photo-filled type for one emotional headline only; huge periodic symbols (Au, Ag) as the identity's display type, with the rock overlapping letters.
- Text is tight, sentence case, left aligned; centred only inside wheels/rings.
### For us
- Add a "sage-white" paper (#EBF0EC) to the minimal palette; let the photographed material carry colour; one industry accent per concept; hierarchy by opacity lists.

## Holographik Instagram grid: why it looks consistent (refs: holographik-ig-grid-1..6.png)
- Colour changes per project (Bottone red, Buffalo green, Alaba purple, Sui blue, CoMinVi grey+orange) but the FRAME never changes: every tile is one finished, full-bleed image, no borders, no caption text added on top, no template.
- Base is dark: roughly 6 in 10 tiles are black/night; white and light-grey tiles break it up; at most one loud colour tile per row.
- A small set of presentation types repeats forever: device in a real scene (phone in hand, laptop on stone, monitor on desk); pages/boards collaged on grey or black; a giant type tile (award or poster); a logo/mark alone on black; one 3D object hero; merch on a chair or keys.
- Projects arrive in clusters of 2-3 neighbouring tiles (CoMinVi phone + brand board + Site of the Day; Paul Kalkbrenner poster + laptop + stage), so a row reads as one chapter.
- Type is huge and cropped or tiny; never a medium paragraph.
- Recurring series: "Site of the Day" award tiles, each set in that project's own type and colour.
- One focal point per tile; it still reads at thumbnail size.
## For us
- Keep every tile one finished frame (no added caption text), a dark/bone base, at most one loud tile per row, and post a project as a 3-tile row: device scene, system board, mark or type tile.
