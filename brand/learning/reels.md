# Reel study notes
Daily: 3 sheets from brand/refs/reels/ + 1 external source. Rules: hook in 1 s, one idea per reel, sound to the cuts, loop or end on the mark.

## Study: merch flash loop, a talking-head list reel, a laptop-on-stone site reel
Sheets: reel-3113c18e (merch, hands only), reel-24210ed3 (creator "5 plugins" list), reel-1a6bfe20 (Holographik CoMinVi laptop on rock).
- Hook (first second): merch reel opens mid-action on the lit lighter, no intro. Creator reel opens on a full-sentence caption at the top ("Don't use X without these 5…") = question + number. CoMinVi opens on a black screen with a tiny mark, i.e. a slow hook that only works because the laptop-on-rock still is already striking.
- Cut rhythm: merch = strict A/B alternation (lighter / beanie) every frame of the sheet, ~0.5 s per shot, 8 pairs, perfect loop. Creator = talking head every other shot, B-roll screen inserts ~1 s each, numbered beats 1-5. CoMinVi = one locked shot ~16 s, the screen content changes (hero, story, rock video, values list).
- Camera: merch and CoMinVi locked off; all movement is inside the frame. Creator: handheld selfie.
- Type: creator uses one-word caps captions centred low ("THESE", "PLUGIN", "NO.2") changing every word, plus a 2-line title at top; CoMinVi type lives only inside the screen (Honesty / Respect / Integrity / Loyalty, active word black, rest ~20% grey, stepping down one per beat).
- Transitions: hard cuts only in all three. No wipes, no zooms.
- Sound (from the pace): merch is beat-cut, one hit per shot; creator is voice-led; CoMinVi reads as a slow ambient bed with soft clicks on screen changes.
- Loop/ending: merch loops seamlessly (last frame = first). Creator ends on "Follow and comment 'Plugin' and I'll DM you" held 2 shots. CoMinVi ends on the values list, which loops back to black.
- Cover: merch = lighter frame; CoMinVi = laptop on rock (works as a still at 3:4).
- For a minimal feed: take the comment-keyword ending (we already use "comment 11"), the numbered beats and the opacity list. Skip the talking head, emoji and word-by-word caps captions.
## External: School of Motion kinetic type part 1 + sound-to-motion rules (cursa.app)
- Markers on the comp at every audio beat; nudge visuals 2-3 frames EARLY so the eye lands with the sound.
- Stagger elements 1 frame apart; a reveal of ~4 frames; exits ~8 frames with a long eased tail.
- One-node camera on nulls, moves overlapped; start the slow zoom-out a few frames before the main move ends.
- Sound: whoosh starts just before a transition, hit on the new state; soft tick on small highlights; only 3-5 accent sounds per piece; one music bed; test at low volume; short tails.

## Study: a held still with type in the corners, a poster that rebuilds itself
Sheets: reel-0148ef71 (Holographik "Colonize Mars"), reel-0986ee33 (Bottone x Holographik poster, Berlin to Zagreb).
- Hook: Mars opens on the finished frame, a planet edge lit from the right, with the title already there. No build-up; the still is the hook. Poster opens on a red poster in a real concrete underpass, so it reads as a photo before it reads as motion.
- Cut rhythm: Mars is one shot; the only change is the title stepping between corners (top-right, centre-left, bottom-right) about every second. Poster is one locked shot of 16 states where the black shape melts and rebuilds behind the type, about 0.5 s each.
- Camera: both locked. All motion happens inside the frame.
- Type in and out: hard swaps, no fades. Same grotesk caps, same size, only position changes. On the poster the type gets eaten by the shape and comes back.
- Transitions: none; the frame changes state.
- Sound (from the pace): a steady ambient bed with a soft tick on each type move.
- Cover: any frame works because the layout never changes. That is the reason to build reels this way for a minimal feed.
## External: SocialPilot reel guide (Sept 2026) + Mosseri notes (zoomsphere.com)
- Something must move within 0.5 s, and the first 3 s decide completion. A 90 s reel that's watched to the end beats a 3 min reel that isn't.
- Put a keyword line on screen and in the caption; Instagram reads both for search and for "Your Algorithm" topics.
- Trial reels (1,000+ followers) go to non-followers first. Test different versions, never the same one twice.
- No other app's watermark on export. Sends per reach is the number to watch.
- For us: a 6 s "9.6 s" reel where a phone-sized frame stays empty while a counter runs to 9.6, then the hotel photo lands. Movement starts at frame 1 (the counter), the empty wait is the story, and the cover is the final frame.
