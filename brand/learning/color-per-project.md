# Colour per project (Zayn's rule)

Zayn: the references don't recycle colours; they research colours for every project. Our design system colours are not a palette for all work.

1. **Studio colours** (Ink, Bone, Ash, Sage white, Stage, Powder, Infrared) frame May11Leven's own voice: studio cards, labels, our name, the cover of the Figma studio file.
2. **Service colours** (Clay, Lake, Cobalt, Ochre, Moss, Kelp, Signal) are small markers only, such as a dot or an "02 Web" label. They never colour a whole post or a client's work.
3. **Every project gets its own palette, researched from its world:**
   - **Material:** the product, packaging, surfaces.
   - **Place:** light, landscape, architecture, culture (with respect, no clichés).
   - **Audience:** who buys and what feels trustworthy to them.
   - **Category gap:** what competitors own, so we pick what they don't (e.g. clinics use clinical blue, so Kora gets sage).
   - Name every colour with its reason, keep 3–5 tones (bg, surface, primary, accent, text), check contrast (4.5:1 text, 3:1 large and UI), and never reuse a past project's palette.
4. **Figma:** each project is a mode in the "Project Palettes" collection of the studio file (May11Leven Labs — Studio, student team). Set the frame's mode and everything rebinds. Examples there: Kora Dental, ata, Inzu.
5. **Feed check:** no two neighbouring tiles share a project palette, and no service colour floods a tile.
