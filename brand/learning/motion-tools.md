# Motion, 3D and shader tools (licences checked 18 Nov)

| Tool | What it is | Licence | Use it for |
|---|---|---|---|
| HyperFrames | HTML/GSAP to MP4, deterministic | Apache-2.0, free (telemetry off, never the Pro/AI features) | Default for reels: UI walkthroughs, type, charts |
| Motion Canvas (`@motion-canvas/core` 3.17) | Code-driven vector animation with a timeline editor, made for explainer videos | MIT, free | Diagram explainers where every line and arrow animates precisely (how an automation or agent works) |
| Zdog (1.1) | Tiny pseudo-3D engine for flat, round, designer-friendly 3D on canvas or SVG | MIT, free | Light playful 3D objects and icons for the bright consumer look, small web touches; Blender stays for realistic 3D |
| Remotion (4.0) | React to video | Free for individuals and companies of up to 3 employees, including commercial work; a paid company licence is needed above that | Data-driven or templated video series. Check our headcount before each use: if May11Leven grows past 3 employees, stop and tell Zayn |
| LYGIA | A large shader function library (noise, blur, lighting, colour) | Prosperity Public License 3.0: free only for non-commercial use, commercial use limited to a 30-day trial, then a paid Patron licence | Study only, never in client or marketing work. Use the ideas, write our own shaders or use MIT/Apache shader code instead |

Rule: check the licence again before shipping work made with any of these, and record the version used in the project's INVENTORY.md.
