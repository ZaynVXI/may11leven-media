# UI/UX: what's current
- Tools: UI/UX Pro Max (reference library), UI Skills baseline-ui (anti-slop), prototype recorder, GSAP/Motion/Lottie/Rive.
- Anti-slop: no purple gradients or glow, one accent per view, balanced headings, tabular numbers.
- Holographik minimal UI (ANI.AI): white screens, huge air, tiny calm text, one accent colour for one action or one moment, big numerals for the number that matters (28%, 8/30, 398), dot-and-line charts, AI chat 'Ask anything' bar; spacing specs drawn as content (16px/12px annotations on line-art devices) (behance.net/Holographik)
