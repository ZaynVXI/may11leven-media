# Reel library (frame sheets of every reel Zayn sent)
Each file is 16 evenly spaced frames of one reel (8x2). Use them in the daily reel study: pick 3, read the cut rhythm, camera move, type timing, transitions, sound cues (from the edit pace), cover frame and ending.
Sources by batch: WOB Studio, Obrazur, Blacklead, .raw, Artycoders, kayvon.ai, Zachary Winterton, Holographik (ANI.AI, Mars, DeepBook, Bottone, CoMinVi), Artemii Lebedev (OXI, Haven, Contour, Edge), Satto.studio, Kedasha (security CLI), plus earlier Inzu prototype references.
Rules: study the thinking, never copy a reel shot for shot; no faces from these reels in our work.
