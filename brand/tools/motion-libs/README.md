# Motion and 3D libraries (installed on demand)

Install in a session: `mkdir -p ~/motion-libs && cd ~/motion-libs && npm install --ignore-scripts animejs lottie-web ola @babylonjs/core @motion-canvas/core @motion-canvas/2d motion`

| Library | Licence | We use it for |
|---|---|---|
| Motion (motion.dev) + motion-ai-kit skill | MIT | UI motion in sites and apps: springs, layout transitions, scroll |
| anime.js (juliangarnier/anime) | MIT | Timeline animation of SVG and DOM: the sail mark drawing in, counters, staggered type |
| Lottie (airbnb/lottie-web) + motion-design skill | MIT | Lightweight vector animations on sites and in apps (icons, the mark) |
| Motion Canvas (motion-canvas/motion-canvas) | MIT | Code-driven explainer videos: process, systems, data, rendered to video |
| Ola (franciscop/ola) | MIT | Smooth number interpolation (prices, live counters, progress) |
| Babylon.js | Apache-2.0 | Real-time 3D on the web (interactive objects, product viewers) |
| Remotion (remotion-dev/skills) | Remotion licence; free for individuals and small teams, check remotion-license before client work | React-based video: reels, captions, data stories |

Skills that go with them: motion-ai-kit, motion-design (LottieFiles), remotion-*, transitions-dev, may11leven-motion.
Not installed: scenario-labs/blender-plugin. It sends scenes to Scenario's paid AI generation (images, video, 3D, materials), which breaks our no-AI-imagery rule and needs a paid account. Revisit only for greybox layout if Zayn decides.
