# thinking-orbs: provenance
- Source: https://github.com/Jakubantalik/thinking-orbs (commit de85557), npm `thinking-orbs` 0.3.1
- Author: Jakub Antalik. Licence: MIT (LICENSE kept). Commercial use allowed; keep the copyright notice.
- Checked before adding: no install/postinstall scripts, no network calls in src (plain 2D canvas only).
- What it is: dotted loading orbs for AI and agent interfaces. Nine states (working, searching, solving, listening, connecting, weaving, composing, breathing, shaping), sizes 64 and 20, auto dark/light, reduced-motion safe.
- Use for May11Leven: waiting states in apps and sites we build (AI agents, automation, booking flows). In React: `npm install thinking-orbs`, then `<ThinkingOrb state="searching" size={64} />`. Credit the author in the project licence notices.
